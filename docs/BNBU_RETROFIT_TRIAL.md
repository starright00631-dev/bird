# BNBU pane retrofit trial preregistration

Compare one defined retrofit package with a contemporaneous control in paired interference neighborhoods. The plan uses the physical pane registry, reviewed approach-side evidence, the decision engine and the [intervention sources](../data/reference/intervention_evidence.csv). Follow-up covers the target and adjacent glass, the frame and any trial screen.

Run the fictional example from the repository root.

```sh
python -m birdglass.retrofit_trial --plan data/examples/synthetic_retrofit_trial.json --output path/to/retrofit_trial_report.json
```

The example has one simulated treatment–control pair and illustrative effort targets. It exercises a reflective/transmissive case, flagging a screen entanglement veto and proposing full-pane exterior visible markers for mechanism review. Local effects and intervals are empty.

## Register before monitoring begins

Use `bnbu_preregistration` and attach a field pane registry. Cite the matched glazing assembly, inspected existing pattern, approach-side view and lighting, 50 m canopy cover and bird flow for each primary pane. Set matching tolerances and the expected independent pair count before assigning treatment. For randomized pairs, the validator traverses sorted pair IDs and applies the recorded Python random seed to the sorted pane IDs. Record the assignment and its source in the frozen plan.

Use separate before and after windows, concurrent observation in both arms and comparable time-of-day, weather and season coverage. Record the planned camera hours, target approaches and effective patrol hours in each arm and period. Before allocating a field sample, estimate baseline rates and cluster variability in a separate blinded pilot and justify precision for the minimum meaningful absolute risk difference. Retain repeated baseline blocks to assess pretrends.

The primary endpoint is first contact on any monitored surface per at-risk approach. Record target, adjacent glass, opaque frame, screen, fully observed clearance, censored trajectory and recording gaps. Track injury with an explicit unknown state. Use the [BNBU monitoring intake](BNBU_MONITORING_PIPELINE.md) for consistent approach/patrol separation and register any protocol adaptations for injury or screen follow-up. Patrol detections remain a separate effort-based endpoint. Record standardized zeros and local searcher-efficiency/persistence trials, along with coder disagreement and missing camera coverage.

Lock the analysis, compliance checks and stopping rules before the intervention. A registered analysis should compare the arm-by-period contrast with uncertainty at the independent assignment level, document concurrent changes and missing-data sensitivity, and report the transferred contact and injury outcomes. Keep field approval and study results linked to the frozen plan. If intervals still span the meaningful effect, obtain more independent pairs and repeated matched effort. If detection is sparse, increase visibility and local detection/persistence assessment before interpreting patrol outcomes.

## Compare candidate feasibility

Record the cost quotation, maintenance and daylight implications for every candidate under review. Each physical or ecological check takes a sourced `pass` or `veto` with the reviewer note and time. Unresolved checks remain pending. Missing site reviews or a veto block the selected treatment from proceeding through this preregistration assessment.

For an existing pattern, record the inspected surface, full-pane coverage, maximum gap on each axis, minimum visible feature, contrast and the photographed light conditions. Use the [intervention evidence matrix](INTERVENTION_EVIDENCE_MATRIX.md) for the scope and limits of the published guidance. Screen/cord trials require wind-load, entanglement and stand-off review. Shading needs the reflection pathway verified at multiple times and angles. Night controls require measured light, local nocturnal activity and emergency/access lighting review. Interior measures, UV-only patterns and vegetation changes have separate evidence requirements shown in the candidate table.

The output records mechanism fit and review feasibility. Local efficacy and an uncertainty interval require comparable BNBU post-treatment and control observations evaluated against the preregistered endpoint. A pilot plan provides no installation authorization.
