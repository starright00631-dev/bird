# 科学模型：从鸟类空间活动到具体玻璃面片的可干预风险

## 1. 我们实际上要识别的对象

在鸟类种群 s、日期 t、地点 x 和玻璃面片 p 条件下，期望发生的真实碰撞可以拆为：

    L[p,s,t] = encounter_flow[s,t,x]
                * E_{route | species, habitat, weather, time}[
                    I(3D route intersects pane p)
                    * P(no successful avoid | optics, pose, kinematics, species, time)
                  ]

报告中的事件不是 `L`，而是其下游被发现部分：

    Y[p,t] ~ Poisson( L[p,t] * P(evidence remains) * P(searcher detects | remains) )

其中机会型/自发上报（BNBU 48 条）没有已知巡查分母，不能强制解释为零值采样。若只知道 Y，就只能识别上述几个相乘因素的乘积；不可能独立学习鸟类到达率、撞击易感性、尸体留存率、发现率。`birdglass/observation.py` 有可以复算的等价例子。

## 2. 五层状态及传递路径

### A. 空间—生态生成（核心，而非巡查）

候选变量必须存在对接来源，而不能靠编造“冬季系数”或“植被系数”：

- 鸟类分布（species x season x time）：重复样点的声学记录、努力量校正的 eBird / 校内鸟类路线；BirdCLEF 的声音识别只是传感器算法，不能直接当鸟只数。
- 生态结构：多尺度植被、树冠层通视、山坡坡向、池塘、栖息与觅食吸引、风向、建筑的可通行性和照明。中国 2025 年 3,078 栋建筑研究提醒：建筑 5m 内树木的关联方向可不同于 1km/10km 植被背景。
- 行动路网：起点（树木、湿地、山侧林缘）、终点（觅食/休憩点）和遮挡；显式模拟穿过某块玻璃的路径流量，而不是“把每块窗户的风险相加”。

当前脚本内三个测试场景的所有路线、面片、方向、权重和高度都是**虚构几何敏感性样本**，不是对 BNBU 实体的复现。BNBU 空间工程只在真正完成轨迹/风险估计后进行对接。

### B. 有限时间的三维动力学与身体几何

轨迹 `r(t)` -> `v = dr/dt`；`a = dv/dt`；`kappa = ||v x a|| / ||v||^3`；法向冲量尺度 `m |v_n|`；法向动能 `0.5*m*v_n^2`。后两者是冲击强度代理，不能未经实验转换为致死率。

躲开面片边缘的必要条件：

    t_available = distance_of_detection / normal_speed - response_latency
    required_acceleration = 2 * distance_to_an_ACTUAL_clear_gap / t_available^2

这是**理想化最小加速度下界**，不是鸟类转弯实际轨迹。特别修正：绕开原面片却进入相邻玻璃不能当作成功避障；代码先合并共面遮挡区间才计算真正的间隙。纵深环境、垂直方向生理约束、落点环境尚未纳入。鸟展开的翼尖可能先撞上玻璃；AVONET 的 Wing.Length 是翼弦长度，**不是翼展**，因此不能擅自计算通行净空。

2026 双目资料为 360 组 120 fps 鸟与鸟避让的轨迹；2017 Dryad cliff swallow 样本为鸟群避让轨迹；2021 Dryad 虎皮鹦鹉穿越不同尺度缝隙的实验包含收翼/减速。这三种数据分别适合曲率、体姿、穿越约束，但都不能直接代表玻璃可视性。`scripts/trajectory_adapter.py` 支持下载原始 CSV 后转为 SI 单位、按鸟/试次计算统计量；当前未下载这些轨迹，**不得称为已拟合**。

### C. 光学与鸟的感知

一个面片可能同时有“背景景物的镜面反射”与“透过玻璃可见的真实空间”。两者的物理原因不同，内侧百叶只能缓解部分透视幻觉，不能保证去掉室外植被的镜像。Fresnel 方程仅计算单理想界面的角度依赖反射率，并非完整玻璃幕墙的外观。

严谨的成像层需要：实拍 HDR、玻璃反射光谱、太阳高度/天气、摄像机位姿、鸟眼视角和不同鸟类的可检测阈值。不能把“紫外线人看不见”推导成“所有鸟在所有光照下都能看见 UV 膜”。

真正的避障行为还需要连续追踪“何时头部/视线转向、何时开始改变速度或轨迹”。当前 `P(detect)`, `P(choose to avoid)` 是多个明确标为未校准的结构假设组，不能用来输出真实 BNBU 撞击概率。

### D. 从碰撞到伤害再到观测

相同撞击频率不等于相同死亡风险。法向动能与姿态影响冲击代理，组织损伤、不同鸟种耐受阈值未知；外置网挡住玻璃可能把撞击转移到网面，只有测得网面缓冲/变形和鸟类伤害才能证明降低了总伤害风险。

UVic 79 个搜索者效率实验试次中 63 个第一次检出，Beta(1,1) 假设下均值约 0.790，95% 可信区间约 [0.696,0.871]。该数字**不是 BNBU 漏报率**；UVic 的 82 个鸟尸留存记录还涉及右删失，不能直接做简单常数修正。

### E. 反事实干预（既有建筑不可轻易改动）

多个 *类型* 的干预应在同一风险端点下比较，而不是所有玻璃贴东西：

| 干预 | 主要作用路径 | 与固定建筑兼容性 | 尚缺证据/风险 |
| --- | --- | --- | --- |
| 外侧高对比规律点阵 | 破除视觉连续性，增加可察觉线索 | 既有玻璃可局部施工 | 具体鸟种/光谱、维护、美观 |
| 外挂细绳帘 | 分割假性通道与反射，尽量不贴玻璃 | 既有廊桥/阳台 | 5cm/10cm 设计按适用规范核验；风载及安全 |
| 外置网/纱屏 | 物理拦截 + 减小反射 | 一层及低层部分可做 | 鸟是否可能撞伤网面；张力、退让距离、安全维护 |
| 室外遮阳百叶/格栅 | 改变太阳光、透射反射与几何遮挡 | 既有立面部分可外挂 | 需要风/结构/消防/采光评价；效果未定 |
| 夜间分区减灯/遮光 | 改变夜迁吸引和空间分布 | 管理措施，不改玻璃 | 非夜行风险不减；场景、人体安全依赖 |
| 移动室内植物、内置遮帘 | 缓解特定透明通道幻觉 | 容易执行 | 不直接消除外部镜面反射 |
| 微型栖地路线引导 | 减少高危路径经过玻璃 | 生境设计，不一定改建筑 | 中国近距树木关联复杂；生态副作用及因果不明 |
| UV/声光驱避 | 某些鸟种/条件可能感知 | 取决于设施 | 不可默认有效、对其他动物干扰及低光问题 |

必须在优化中单独约束视觉负担、成本、鸟类和人类安全、生态连通性。当前“成本单位”和“美观损失单位”均为假设，**不是采购报价或真实满意度**。

## 3. 为什么必须进行多传感器设计

只有碰撞报告，无法识别碰撞率的机制分解。最小可辨识方案需要：

1. 迁飞/栖地背景：同一地点重复声学采样（附有效录音努力量）、标准化路线鸟数（避免把声音分类概率当鸟只数）、日周期/风和植被状态。
2. 关键局部飞行路径：可校准的多视角相机或雷达/热红外记录 3D 轨迹，包含“靠近而未碰撞”的事件及真正没经过的时间段；记录摄像机检测率和闭塞。
3. 玻璃感知证据：同一点位不同时段的反射/透明影像或光谱，鸟类起动避让的距离、翼姿、加速度；至少把镜面反射与透视分别编码。
4. 伤害/观测：视频碰撞与病理/随访结果，标准化地面巡查，搜索者检出率与尸体/羽迹存留。
5. 干预前后：预注册的 matched-pane / step-wedge 实验，外置点阵/绳帘/网罩/熄灯均用独立对照。主要结果同时报告每次接近中的撞击率、每实际飞行路径的伤害、外观/维护接受度。

只有拿到这些数据后才能把 `mechanism.py` 假设概率换为层级贝叶斯后验、做留地点/留季节验证，然后回到 BNBU 三维模型选择具体玻璃面片。

## 4. 现有结果的真伪边界

**真实验证**：756 行 UVic 建筑-日观测的整批次留出 Poisson 基线；数值单元测试 17 项；基于实际 UVic 搜索者实验的 Beta 计算。

**未校准实验**：所有三种校园形态场景、面片优先级、造价/美观权重、视觉机能、窗户反射概率、环境导流系数、UV/光照作用系数以及反事实防撞比例。

**不应主张**：BNBU 真实窗格碰撞概率；哪种设备已获证实必胜；真实鸟类运动参数已经通过 2026 轨迹训练；“临山宿舍一定需要/不需要施工”；冬季较高或较低的普遍结论。
